# Profil domu

**Priorytet:** P0 · **Gdzie:** Ekran 0 (pierwsze uruchomienie), edycja: Ustawienia → Profil ([ekran 4](../../03-ekrany/ekran-4-profil.md)) · **Offline:** tak

## Co robi

Zbiera zawczasu informacje o domownikach i mieszkaniu. Profil jest tylko lokalny (bez kont). Służy jako kontekst dla AI: na jego podstawie powstaje [plan 72 h](plan-72h.md), a odpowiedzi w [czacie](../01-czat/czat.md) dotyczą twojej rodziny. Kontakty ICE służą do SMS-ów z [panelu alarmowego](../05-alarm/panel-alarmowy.md).

## Pola profilu

| Grupa | Pola |
|---|---|
| Domownicy | Wiek lub grupa wiekowa, niemowlę, senior, ciąża, niepełnosprawność, ograniczona mobilność |
| Leki | Nazwa, czy wymaga lodówki (np. insulina), zapas w dniach |
| Urządzenia zależne od prądu | Koncentrator tlenu, ssak, wózek elektryczny, pompa |
| Zwierzęta | Gatunek, liczba, transporter |
| Mieszkanie | Piętro, winda, rodzaj ogrzewania, kuchenka (gaz/prąd), piwnica |
| Transport | Samochód, rower, brak |
| Zapasy | Woda, żywność, latarka, radio, powerbank (z datą sprawdzenia) |
| Kontakty alarmowe | Imię i numer bliskich (ICE) |

## Wypełnianie

- Kilka krótkich ekranów, łącznie około 2 minut.
- Każde pole można pominąć.
- Profil można zmienić w każdej chwili. Kolejne odpowiedzi czatu uwzględniają zmianę.

## Prywatność

Profil zostaje w telefonie (szyfrowanie bazy: po MVP). Opuszcza go tylko wtedy, gdy sam go wyeksportujesz albo wyślesz SMS do bliskich z dołączonymi danymi z profilu (można to wyłączyć). Można go wyeksportować lub usunąć w [ustawieniach](../../03-ekrany/ekran-3-ustawienia.md).
