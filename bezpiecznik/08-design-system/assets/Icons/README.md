# Icons

Zestaw Lucide (ISC), obrys 2, 24 px, kolor podglądu `ink-100` `#EEECE6`. W aplikacji importuj z `lucide-react` — tam kolor bierze się z `currentColor`.

| Ikona | Znaczenie w Bezpieczniku |
| --- | --- |
| `shield` | schron / miejsce schronienia |
| `house` | profil domu |
| `droplet` | punkt poboru wody |
| `hospital` | szpital |
| `flame` | straż pożarna (PSP) |
| `heart-pulse` | pierwsza pomoc |
| `compass`, `navigation`, `map-pin` | kompas, nawigacja, punkt na mapie |
| `wifi-off`, `plane` | offline, tryb samolotowy |
| `pill`, `refrigerator` | leki, leki w lodówce |
| `baby`, `paw-print` | niemowlę, zwierzę w profilu domu |
| `backpack` | plecak ewakuacyjny |
| `battery-low` | oszczędzanie baterii |
| `phone` | połączenie 112 |
| `triangle-alert` | ostrzeżenie / brak źródła |
| `book-open` | źródło oficjalne |
| `check` | krok wykonany (plan 72h) |
| `arrow-up`, `mic`, `plus` | composer: wyślij, dyktuj, dodaj |
