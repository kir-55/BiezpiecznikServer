# Logo

Znak Bezpiecznika: geometryczna litera **B** (`#EDEDEA`) z ochrowym krzyżem pomocy (`signal` `#C9A66B`) w środku — „B jak Bezpiecznik, + jak pomoc”.

| Plik | Do czego |
| --- | --- |
| `bezpiecznik-app-icon.svg` | Ikona aplikacji / PWA / favicon. Zaokrąglony kwadrat (1024 px, promień 230 px ≈ 22% — kształt jak na iOS) w `bg-100` `#181715`, znak wyśrodkowany, wysokość ~59% ikony (mieści się w strefie bezpiecznej masek Androida). |
| `bezpiecznik-znak.svg` | Sam znak, bez tła — do nagłówków, ekranu powitalnego, slajdów. Tylko na ciemnym tle (`bg-000`…`bg-200`). |

Zasady:
- Nie zmieniać kolorów znaku; na jasnym tle nie używać wersji bez tła — użyj ikony aplikacji.
- Minimalny rozmiar ikony: 24 px. Wokół znaku pole ochronne ≥ szerokość ramienia krzyża.
- Krzyż zawsze w ochrze, nigdy w czerwieni (czerwony krzyż na białym tle to chroniony znak Czerwonego Krzyża).
- Wordmark „Bezpiecznik” składamy krojem Atkinson Hyperlegible Next ExtraBold, `ink-100`, obok znaku.
