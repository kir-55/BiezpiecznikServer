# ScreensChat

Makiety E1 złożone z komponentów systemu (390 × 844). Treści i numery stron są przykładowe.

Układ: wyspa (lewo), pigułka stanu (środek), SOS (prawo) 48 px od góry; pod nimi gradient tła, treść przewija się pod spodem. Wiadomości 16 px od krawędzi, odstęp 20 px. Composer 12 px od krawędzi, nad paskiem gestów. Przypięty instruktor RKO nad composerem.
