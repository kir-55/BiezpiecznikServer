# Composer

Pole wpisywania pytania — kopia proporcji ChatGPT: pigułka `radius-xl` (28 px), min. 52 px wysokości, tło `bg-200`, ramka `line-150`, po focusie `line-200`.

- Rośnie z tekstem do 200 px, potem przewija.
- **Enter** wysyła, **Shift+Enter** nowa linia. Wysłanie przycina spacje; pusty tekst = strzałka wyłączona.
- `busy` — model odpowiada: spinner na strzałce, wysyłanie zablokowane.
- `onAttach` / `onVoice` pokazują „+” i mikrofon (bez nich ich nie ma).
- Tekst ma 16 px — mniej powoduje automatyczny zoom na iPhonie.

Na telefonie: przyklejony do dołu ekranu, `space-4` od krawędzi, nad klawiaturą.
