# QuickActions · JumpToLatest

- `QuickActions` — siatka 2 × 2 w pustym czacie: Ktoś nie oddycha · Brak prądu · Alarm / schron · Ewakuacja. Kafelek min. 88 px, ramka `line-150`, ikona u góry, etykieta 16 px pogrubiona — jak karty sugestii ChatGPT. „Ktoś nie oddycha” ma ikonę w `sos-text` (jedyny kafelek zagrożenia życia). Dotknięcie wysyła etykietę jako wiadomość i wstawia odpowiedź bez AI.
- `JumpToLatest` — pigułka „↓ Nowa odpowiedź”, gdy użytkownik czyta wyżej, a przyszła odpowiedź. Lista nie przewija się sama.
