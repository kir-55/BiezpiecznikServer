# OfflineBadge

Stały znacznik w nagłówku: aplikacja działa bez sieci. Jury musi go widzieć przez całe demo.

- `mode="offline"` (wifi-off) lub `"airplane"` (samolot).
- `children` — własny tekst, np. „Offline · baza z 12.11” (data pobrania danych).
- Kolor `verified`: brak sieci to tu **stan normalny i dobry**, nie błąd.
