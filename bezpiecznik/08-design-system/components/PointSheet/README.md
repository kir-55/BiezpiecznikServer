# PointSheet · NearestList · LayersSheet

Zawartość arkuszy na ekranie Mapa (w `Sheet`, maks. 70% wysokości).

- `PointSheet` — rodzaj, nazwa 20 px, adres, dostępność, odległość + kierunek świata + strzałka, status (✓ Potwierdzony w `verified` / ? Niepotwierdzony z wyjaśnieniem), źródło i data weryfikacji, ostrzeżenie o starych danych. **Prowadź** (`primary`) i **Kompas** obok siebie, po 44 px.
- `NearestList` — trzy najbliższe schronienia, wiersz 56 px: znacznik, nazwa, odległość, strzałka względem kierunku patrzenia.
- `LayersSheet` — `ListRow` ze znacznikiem warstwy i `Switch`.
