# SourceChip

Dowód, że odpowiedź pochodzi z oficjalnego źródła: wydawca · tytuł · strona na `verified-tint`. Zielone tło = „cytat ze źródła, nie opinia modelu”.

- `onClick` / `href` otwiera lokalny PDF na tej stronie — **pokażcie to na scenie**.
- Bez `title` dla krótkich źródeł (`PSP · s. 7`). Za długi tekst ucina się wielokropkiem.
- Kolor `verified` tylko dla źródeł oficjalnych. Nigdy dla „zapisano” ani sukcesu.
